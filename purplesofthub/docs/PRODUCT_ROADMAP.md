# PurpleSoftHub Product Roadmap

## Planned Implementation Order

1. Platform Shell
2. Core Platform Services
3. Academy
4. AI Course Commerce
5. Music Platform
6. Marketplace
7. Agency Workspace

## Sprint Map

### Sprint 3 — Platform Shell v1.0

Shared authenticated chrome only. No product business logic.

Delivered:

- Reusable AppShell, sidebar, and topbar
- Configuration-driven navigation
- Placeholder module routes under `/platform`
- Light / Dark / System theme support
- Architecture, design system, and roadmap docs

### Sprint 4 — Core Platform Services

Shared services that later products will consume:

- Session and workspace context
- Notifications backend
- Files and storage primitives
- Billing primitives
- Support primitives

### Sprint 5 — PurpleSoftHub Academy

Learning product inside the shared shell, including the AI Video Creation Course.

### Sprint 6 — Music Services Platform

Artist campaigns, releases, and promotion operations.

### Sprint 7 — Marketplace

Digital products and commerce surfaces.

### Sprint 8 — Agency Workspace

Client delivery, briefs, and project operations.

## Roadmap Principle

Each sprint should add one coherent layer of product value without weakening the shared shell or creating duplicate layout systems.

The marketing website, existing authentication, and current dashboard/admin implementations stay in place until a dedicated migration sprint replaces them.
