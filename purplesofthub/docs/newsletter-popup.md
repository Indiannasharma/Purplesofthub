## Interface and integration

The popup uses the official existing PurpleSoftHub PNG, the project's existing Outfit typography, semantic light/dark tokens and an isolated CSS module. Desktop is a 780px editorial two-column dialog; mobile is a compact bottom sheet. Existing Radix Dialog provides semantics, focus containment and Escape dismissal. Initial focus goes to the title instead of opening a mobile keyboard. Closing restores the previous focus. CSS entrance/exit animations are disabled under reduced motion. A lazy import and isolated error boundary keep the popup off the initial render and protect essential page content if its chunk fails.

Only the existing `/api/newsletter` endpoint is used. Its new GET capability response returns an availability boolean and no subscriber records; the controller calls it after engagement qualifies, without blocking server rendering. A failed capability check prevents display. POST remains the existing subscription and welcome-email implementation, with safe normalization, checked lookup/reactivation failures, verified duplicate handling, sanitized source labels and removal of verbose subscriber/database-error logging. It never returns success for an unconfirmed reactivation.

The shared client submission helper requires both HTTP success and `success:true`, enforces a 15-second timeout and locks in-flight submission. Homepage and Insights forms reuse it and record confirmed subscription success. The homepage form's previous immediate loading reset and incorrect final loading state were corrected. No new table, competing API, font package or credential is introduced. GA4, Paystack, authentication, payment configuration and unrelated database code are unchanged.

## Timing and persistence

- 45 seconds of visible, focused-tab engagement, or 20 seconds plus 60% current-page scroll, whichever qualifies first.
- Per-page engagement resets on pathname changes. Hidden/unfocused time is not counted.
- Active form controls, dialogs, consent panels, payment iframes and full-screen checkout overlays defer display. A reduced mobile visual viewport also defers display while the keyboard is open.
- Once per tab session via sessionStorage, with BroadcastChannel coordination across concurrently open same-origin tabs. No visitor identifier or email is persisted.
- Close, backdrop dismissal, Escape and Not now suppress for 14 days. Confirmed subscription suppresses permanently in that browser; closing its success panel does not overwrite that preference.
- Blocked storage falls back to memory without crashing. Durable suppression cannot survive a reload if both relevant storage mechanisms are blocked; cross-tab coordination is best effort when BroadcastChannel is unavailable.
- Public marketing pages only. Admin, workspace/platform, authentication, checkout/callback, recovery and preview paths/queries are excluded; noindex pages also defer display.
